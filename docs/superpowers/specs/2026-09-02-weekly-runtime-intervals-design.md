# 目标管理：顶层 + 叶子运行时段周视图

## Goal

在「目标管理」里用自然周日历看真实运行时段：列是周一到周日，行是 0–24 点（0 在上）。每段同时记下**顶层目标**和当时聚焦的**叶子**（无子树时叶子与顶层是同一个）。一直按年月日记录，运行时计入。悬浮窗不加这条轴。

## Scope

- **In:** 时段日志（开/关段、换顶层或换叶子都切段、持久化、周查询、跨日切开）、目标管理第四个 Tab「本周」、正在运行的顶层 + 叶子状态行与图例、相关 unittest。
- **Out:** 悬浮窗目标树、回填上线前的 `active_seconds`、金币/操作数周报、排行榜、中间分组节点单独成段（分组不聚焦，不记时）。

`Task.active_seconds` / 叶子 `active_seconds` 仍只表示终身累计，周视图不扫目标树。

## Architecture

新模块 `src/runtime_intervals.py`：跟踪器、读写、按周切片。`TaskManager.tick_active_time()` 每秒把「这一秒算不算运行时间」、当前顶层 `task_id`、当前叶子 `leaf_id`（无子树则为 `null`）交给跟踪器。UI 在 `src/task_dialog.py` 的「本周」Tab，绘制放在 `src/ui_week_runtime.py`。

日志与主存档分离：`%APPDATA%\Adventure\runtime_intervals.json`（非 Windows：`~/.adventure/runtime_intervals.json`，与 `get_data_dir()` 相同）。不写入 `data.json`。

## Data

文件 schema（`version: 1`）：

```json
{
  "version": 1,
  "intervals": [
    {
      "task_id": "ab12cd34",
      "title": "写文档",
      "leaf_id": "e8f0a1b2",
      "leaf_title": "第 3 章",
      "start": 1756800000.0,
      "end": 1756807200.0
    }
  ],
  "open": {
    "task_id": "ab12cd34",
    "title": "写文档",
    "leaf_id": "e8f0a1b2",
    "leaf_title": "第 3 章",
    "start": 1756810000.0
  }
}
```

- `start` / `end`：本地墙钟对应的 Unix 时间戳（`time.time()`）。
- `open`：正在跑、尚未关闭的一段；没有则为 `null`。
- `title` / `leaf_title`：开段时的标题快照。改名、删除后历史仍用快照。
- 有子树且已聚焦叶子：`leaf_id` / `leaf_title` 为该叶子。
- 扁平目标（无子树）：`leaf_id` 为 `null`，`leaf_title` 为 `null`（身份就是顶层本身）。
- 身份键：`(task_id, leaf_id)`。`leaf_id` 为 `null` 与任何真实叶子 id 都不同。
- 无上限，一直追加。不上线前的累计时长不回填。

跨午夜在文件里可以是一条；绘制时按本地日历日切开。

## Recording

与现有运行时间同一套条件。令

`recording = 显示器亮 且 未空闲 且 存在 ACTIVE 顶层目标 且（无子树，或已聚焦未完成叶子）`

跟踪器每秒看 `recording` 与身份键 `(task_id, leaf_id)`（不看该秒 `active_seconds` 增量，避免首 tick 返回 0 秒时漏开段）：

| 上一秒 | 这一秒 | 动作 |
|--------|--------|------|
| 不计时 | 计时 | 打开 `open`：`start=now`，记下顶层 + 叶子快照 |
| 计时 | 不计时 | 关闭：`end=now`，写入 `intervals`，`open=null` |
| 计时，身份 A | 计时，身份 B | 先关 A，再开 B（换顶层，或同一顶层换叶子） |
| 计时，同一身份 | 计时，同一身份 | 不动 |
| 不计时 | 不计时 | 不动 |

暂停、完成/删除当前目标或当前叶子、关屏、空闲停表、有子树但失去叶子聚焦 → 不计时 → 关段。恢复或空闲结束或重新聚焦叶子 → 下一秒计时 → 开新段。

关段时：时长 < 1 秒则丢弃。刚写入的一段若与上一段身份键相同且 `new.start - prev.end < 2` 秒，则把上一段 `end` 延到 `new.end`，不另存。

未关闭段：随主存档 15 秒自动保存一起写盘（`open` 仍无 `end`）。正常退出、暂停、换顶层或换叶子：立刻关段并写盘。

## Crash and clock

启动时若存在 `open`：

1. 取主存档 `data.json` 的修改时间 `mtime`（秒）。没有该文件则丢掉 `open`。
2. 若 `mtime >= open.start` 且 `now - mtime ≤ 1 小时`，用 `mtime` 作为 `end` 关段（再走 <1 秒丢弃 / 合并）。
3. 否则丢掉 `open`，不把关机后的时间算进去。

系统时间：

- 向前跳：当前 `open` 按新 `now` 关，再按本秒 `recording` 决定是否重开。
- 向后跳超过 1 小时：丢掉 `open`，再按本秒规则重开。

## Query (week view)

自然周：本地周一 00:00:00 到下周一 00:00:00。

查出与 `[week_start, week_end)` 相交的已关闭段，加上 `open`（临时 `end=now`）。每段按本地日历切成若干 `[date, t0, t1, task_id, title, leaf_id, leaf_title]`，其中 `t0`/`t1` 是当天墙钟小时，范围 `[0, 24]`：

`hour = hour + minute/60 + second/3600`，截断到 `[0, 24]`。

夏令时不单独建模：用本地 `datetime` 墙钟映射到 0–24 列高。重叠的一小时画重叠；跳过的一小时画空档。

不能翻到完全在「今天所在周」之后的周。过去周无上限。

## UI

目标管理对话框第四个 Tab：**本周**。进行中 / 已暂停 / 已完成 不变。悬浮窗不加。对话框可加宽到约 640，仅该对话框。

从上到下：

1. **周导航**：`←  2026-08-31 ~ 2026-09-06  →`（该周周一～周日的日期）。
2. **状态行**（由当前 `AppState` 现场算，不读日志）：
   - 有叶子聚焦：`正在运行  顶层「写文档」  ·  「第 3 章」`
   - 扁平 ACTIVE、无子树：`正在运行  顶层「写文档」`
   - 否则：`当前没有运行中的目标`
3. **7 列日历**：表头 `一 31` … `日 06`。每列一条竖轴，0 点在上、24 点在下。刻度标 `0  6  12  18  24`。时段按身份键着色填矩形；同一顶层下不同叶子是不同颜色、相邻两段。空档不填。
4. **今天**：该列一条「现在」横线。`open` 那段画到这条线为止，矩形描边表示仍在长。
5. **悬停**：有叶子时 `写文档 · 第 3 章  09:00–11:20  （2h 20m）`；扁平目标 `写文档  09:00–11:20  （2h 20m）`（标题用快照）。
6. **图例**：本周出现过的每个身份键一行。有叶子：色块 + `写文档 · 第 3 章`；扁平：色块 + `写文档`。正在跑的那一行加「运行中」（顶层与叶子都对上）。已删除的顶层或叶子仍显示快照名。

颜色：固定调色板（约 8 个、无 emoji），`hash(task_id + "\0" + (leaf_id or "")) % n`。同一身份键各周颜色一致。

不显示金币、操作数、排行。只回答「这周 0–24 点被哪些顶层 / 叶子占了」。

目标树原有 ● 标记不变。

## Persistence errors

- 读失败：把文件挪到 `runtime_intervals.broken.<时间戳>.json`，内存空列表继续记；主 `data.json` 不动。「本周」状态行下加一行静默说明：`运行记录已重置`（非模态框）。
- 写失败：本轮跳过，下次自动保存或关段再写；主存档照常。
- `task_id` 或 `leaf_id` 在当前树上找不到：图例与悬停仍用快照标题，当作已删除。

## Testing

`tests/test_runtime_intervals.py`（纯逻辑，不点 UI）：

- 开段 / 关段 / 换顶层先关后开。
- 同一顶层换叶子：先关后开，两段 `leaf_id` 不同。
- 扁平目标 `leaf_id` 为 `null`，换到带叶子的目标会切段。
- `recording` 为假（暂停、空闲、关屏、无聚焦叶子）关段；恢复再开。
- 跨午夜切开，落在相邻两列，叶子字段保留。
- 周查询只含与该周相交的段。
- 关段 < 1 秒丢弃；同一身份键间隙 < 2 秒合并；不同叶子不合并。
- 损坏文件备份并空仓继续。
- `open` 崩溃恢复：用 `mtime` 截断；`mtime` 过旧或早于 `start` 则丢弃。

`tests/test_task_dialog_week.py`（offscreen）：对话框能打开「本周」Tab，网格为 7 列。不测像素。

不改 `tests/test_widget_smoke.py`（悬浮窗几何不变）。
